# Game UI assets / Nguồn hình ảnh

This casual forest skin uses existing 2D artwork, no AI-generated images.
The reference screenshot guided the warm orange/cream palette and rounded UI;
it is not bundled as an asset. Board sectors, scores and rules are unchanged.
